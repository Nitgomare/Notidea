flomo local · macOS 使用说明
================================

一、准备工作
------------
需要 Node.js 22.5 或更高版本（内置的 node:sqlite 从这个版本开始才有）。
  · 装了 Homebrew：  brew install node
  · 没装：           到 https://nodejs.org 下载 macOS 安装包
验证：终端执行  node -v  应显示 v22.5.0 以上。

二、第一次打开
--------------
1. 解压这个 zip，得到一个文件夹（放在哪儿都行，别放系统盘根目录）。
2. 首次运行先给启动脚本执行权限（只需一次）：
       cd 解压后的目录
       chmod +x start.command start-server.command
3. 双击 start.command —— 会自动起服务，并用 Edge / Chrome 的应用窗口
   （没有地址栏，和 App 一样）打开。
   如果双击提示"无法验证开发者"：右键点 start.command → 选"打开" → 再确认一次。

只想用浏览器：双击 start-server.command，然后访问 http://127.0.0.1:7777

三、数据在哪
------------
所有笔记都在程序目录的 data/ 里：
  data/flomo.db      笔记数据库
  data/files/        图片 / 附件
  data/llm.json      模型 API Key（如果配了）
更新程序不会动 data/。

四、更新
--------
设置 → 检查更新 → 下载并安装。
更新脚本会：解压新包 → 覆盖程序文件（保留 data/）→ 自动重启服务。
日志：data/update/download.log 与 data/update/apply.log。
如果自动更新失败，到 release 页面手动下载 zip，把程序文件覆盖过去即可（保留 data/）。

五、从 Windows 迁过来
--------------------
把 Windows 版目录里的 data/ 整个复制到 macOS 版目录下即可，格式完全一样。

六、常见问题
------------
· 提示端口被占用（EADDRINUSE）：已经有另一个 flomo local 在跑，先关掉它。
   终端排查：lsof -nP -iTCP:7777 -sTCP:LISTEN
· 桌面快捷方式：设置 → 创建桌面快捷方式，会在 ~/Desktop 生成
   一个"flomo local.command"，双击即可启动（首次同样可能需要在
   "系统设置 → 隐私与安全性"里允许）。
· 想换端口：服务端读环境变量 PORT，例如
   PORT=8899 sh start-server.command   然后访问 http://127.0.0.1:8899
